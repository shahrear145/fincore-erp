# FinCore ERP — PythonAnywhere (ফ্রি প্ল্যান) ডিপ্লয় গাইড

এই গাইডে ধাপে ধাপে দেখানো আছে কীভাবে আপনার FinCore ERP ওয়েবসাইটটি
**PythonAnywhere-এর ফ্রি "Beginner" প্ল্যানে** চিরকাল ফ্রি হোস্ট করবেন।

> **ফ্রি প্ল্যানে যা পাবেন:** `https://আপনারনাম.pythonanywhere.com` ঠিকানা,
> ফ্রি HTTPS, স্থায়ী ৫১২ MB ডিস্ক (SQLite ডাটাবেস এখানে নিরাপদে থাকে),
> সার্ভার ২৪/৭ চালু (ঘুমায় না)।
>
> **যা পাবেন না:** নিজের ডোমেইন (যেমন `shagorsmeathouse.com`)।
> ইমেইল (OTP/রিমাইন্ডার) **ফ্রি প্ল্যানেও কাজ করে** — ফ্রি অ্যাকাউন্টে
> শুধু Gmail-এর SMTP অনুমোদিত, তাই Gmail App Password দিয়ে পাঠাতে হবে।

## ০. যা যা লাগবে

- একটি PythonAnywhere অ্যাকাউন্ট (ফ্রি) — <https://www.pythonanywhere.com/registration/register/beginner/>
- প্রজেক্টের জিপ ফাইল: **`fincore-pythonanywhere.zip`**
  (এতে `backend/`, `deploy/`, `docs/` এবং আপনার আসল `db.sqlite3` আছে —
  অর্থাৎ এখনকার সব হিসাব, পার্টনার, লেনদেন হুবহু যাবে)
- একটি ব্রাউজার (কোনো আলাদা সফটওয়্যার লাগবে না)

> ⚠️ জিপে `.env` নেই — সেটা সার্ভারে নতুন করে তৈরি হবে (পাসওয়ার্ড/সিক্রেট
> কোথাও আপলোড করবেন না)। `db.sqlite3`-এ আপনার বর্তমান লগইন (যেমন `shagor`)
> আগের পাসওয়ার্ডেই কাজ করবে।

## ১. অ্যাকাউন্ট খোলা

1. উপরের লিংকে গিয়ে **Beginner (Free)** প্ল্যানে সাইন আপ করুন।
2. ইউজারনেমটা মনে রাখুন — এটাই আপনার সাইটের ঠিকানা হবে:
   `https://আপনারনাম.pythonanywhere.com`

---

## ২. কোড আপলোড করা

1. লগইন করার পর উপরের মেনু থেকে **Files** ট্যাবে যান।
2. **Upload a file** বাটনে ক্লিক করে `fincore-pythonanywhere.zip` আপলোড করুন
   (হোম ফোল্ডারে, অর্থাৎ `/home/আপনারনাম/`)।
3. উপরের মেনু থেকে **Consoles → Bash** খুলুন।
4. এই কমান্ডগুলো চালান (প্রতিটা লাইনের পর Enter):

```bash
mkdir -p ~/fincore
unzip ~/fincore-pythonanywhere.zip -d ~/fincore
ls ~/fincore
```

শেষ কমান্ডে `backend  deploy  docs  README.md` দেখতে পাবেন।

## ৩. এক কমান্ডে সেটআপ

Bash কনসোলেই চালান:

```bash
bash ~/fincore/deploy/pythonanywhere/setup.sh
```

এই স্ক্রিপ্টটি নিজে থেকেই:

- `fincore` নামে virtualenv তৈরি করে (Python 3.13),
- প্রোডাকশন ডিপেন্ডেন্সি ইনস্টল করে,
- `backend/.env` তৈরি করে আপনার ইউজারনেম বসিয়ে দেয়,
- **নতুন SECRET_KEY** জেনারেট করে,
- ডাটাবেস মাইগ্রেট ও স্ট্যাটিক ফাইল কালেক্ট করে,
- `manage.py check` দিয়ে যাচাই করে।

শেষে একটি নির্দেশনা দেখাবে — সেটাই ধাপ ৪।

> প্রথমবার ইনস্টল হতে ৩–৫ মিনিট লাগতে পারে। মাঝপথে বন্ধ করবেন না।

## ৪. ওয়েব অ্যাপ কনফিগার করা (UI-তে)

### ৪.১ নতুন ওয়েব অ্যাপ

1. **Web** ট্যাবে যান → **Add a new web app**।
2. **Manual configuration** বেছে নিন (Django অপশন নয়)।
3. Python ভার্সন: **Python 3.13** (স্ক্রিপ্ট শুরুতে যে ভার্সন দেখাবে —
   সাধারণত 3.13 — Web ট্যাবেও সেটাই বেছে নিন)।
4. তৈরি হওয়ার পর **Web** ট্যাবেই সেট করুন:
   - **Source code:** `/home/আপনারনাম/fincore/backend`
   - **Working directory:** `/home/আপনারনাম/fincore/backend`
   - **Virtualenv:** `/home/আপনারনাম/.virtualenvs/fincore`

### ৪.২ WSGI ফাইল

1. Web ট্যাবে **WSGI configuration file** লিংকে ক্লিক করুন।
2. ভেতরের সব মুছে ফেলুন।
3. `deploy/pythonanywhere/wsgi.py` ফাইলের কনটেন্ট পেস্ট করুন।
4. `PROJECT_DIR` লাইনে `__USERNAME__`-এর জায়গায় আপনার ইউজারনেম বসান।
5. **Save** করুন।

### ৪.৩ স্ট্যাটিক ও মিডিয়া ফাইল

Web ট্যাবে **Static files** অংশে দুটি ম্যাপিং যোগ করুন:

| URL | Directory |
|---|---|
| `/static/` | `/home/আপনারনাম/fincore/backend/staticfiles` |
| `/media/` | `/home/আপনারনাম/fincore/backend/media` |

### ৪.৪ Reload

সবুজ **Reload** বাটনে ক্লিক করুন, তারপর খুলুন:

```
https://আপনারনাম.pythonanywhere.com
```

## ৫. প্রথম লগইন ও যাচাই

আপনার পুরনো ইউজারনেম/পাসওয়ার্ড দিয়েই লগইন করুন। তারপর এইগুলো দেখে নিন:

- [ ] **ড্যাশবোর্ড** — হাতে নগদ, বাকি, নিট অবস্থান ঠিক সংখ্যা দেখাচ্ছে
- [ ] **পার্টনার ও বাকি** — পার্টনার ও নামগুলো আছে, হিস্ট্রি ড্রয়ার খোলে
- [ ] হিস্ট্রিতে **✏️ এডিট / 🗑️ ডিলিট** বাটন কাজ করছে
- [ ] **হিসাব সারাংশ** — সমীকরণ মিলছে
- [ ] **সুপার ক্যালকুলেটর** ও এক্সপোর্ট (PDF/Excel) কাজ করছে
- [ ] পেজের ডিজাইন ঠিক আছে (স্ট্যাটিক ফাইল লোড হচ্ছে)

> PDF এক্সপোর্ট সার্ভারে Edge/Chrome না থাকায় বান্ডল করা ফন্ট দিয়ে
> (fpdf2 fallback) তৈরি হবে — বাংলা লেখা ঠিকই আসবে, চেহারা সামান্য আলাদা
> হতে পারে। Excel/Word এক্সপোর্ট স্বাভাবিকভাবেই কাজ করবে।

কিছু ভুল মনে হলে **Web → Error log** দেখুন (নিচের সমস্যা সমাধান অংশ)।

## ৬. ভবিষ্যতে কোড আপডেট করলে

লোকাল পিসিতে পরিবর্তন করার পর:

1. নতুন জিপ বানাতে প্রজেক্ট ফোল্ডার থেকে একবার চালান:

```bash
python deploy/pythonanywhere/build_zip.py
```

   এটি `.env`, `.venv`, `staticfiles`, `backups` বাদ দিয়ে বান্ডেল তৈরি করে
   এবং **চলমান ডাটাবেসের একটি নিরাপদ স্ন্যাপশট** (SQLite backup API) যোগ করে —
   ডেভ সার্ভার চালু থাকলেও নিরাপদ।

2. শুধু বদলানো ফাইলগুলো **Files** ট্যাব → Upload দিয়ে আপলোড করুন
   (অথবা নতুন জিপ আপলোড করে `unzip -o` করুন),
3. Bash কনসোলে:

```bash
cd ~/fincore/backend
source ~/.virtualenvs/fincore/bin/activate
python manage.py migrate --noinput
python manage.py collectstatic --noinput
```

3. Web ট্যাবে **Reload** চাপুন।

> **নতুন ডিপেন্ডেন্সি** যোগ হলে:
> `pip install -r ~/fincore/deploy/pythonanywhere/requirements-pythonanywhere.txt`

## ৭. ব্যাকআপ (খুব গুরুত্বপূর্ণ)

আপনার সব হিসাব `backend/db.sqlite3` ফাইলে থাকে। নিয়মিত ব্যাকআপ নিন:

1. **Files** ট্যাব → `fincore/backend/` → `db.sqlite3` → **Download**।
2. মাসে অন্তত একবার ডাউনলোড করে নিজের কম্পিউটার/গুগল ড্রাইভে রাখুন।
3. অ্যাপের ভেতরের **ব্যাকআপ** ফিচারও ব্যবহার করতে পারেন
   (লোকাল ব্যাকআপ কাজ করবে; S3 ব্যাকআপ ফ্রি প্ল্যানে নেই)।

## ৯. সমস্যা সমাধান

| সমস্যা | কারণ ও সমাধান |
|---|---|
| **"Something went wrong"** | Web ট্যাব → **Error log** দেখুন। বেশিরভাগ ক্ষেত্রে `.env` ভুল বা প্যাকেজ ইনস্টল হয়নি। `bash ~/fincore/deploy/pythonanywhere/setup.sh` আবার চালান। |
| পেজে **ডিজাইন নেই** (স্ট্যাটিক 404) | Static files ম্যাপিং ভুল, অথবা `collectstatic` চালানো হয়নি। ধাপ ৪.৩ দেখুন, তারপর Reload। |
| **403 CSRF** লগইনের সময় | `.env`-এ `CSRF_TRUSTED_ORIGINS=https://আপনারনাম.pythonanywhere.com` আছে কিনা দেখুন, তারপর Reload। |
| **ডাটাবেস লকড** | আমরা `timeout=20` সেট করেছি; একসাথে অনেক ইউজার লিখলে হতে পারে। দোকানের ব্যবহারে সাধারণত হয় না। |
| **ইমেইল পাঠানো যায়নি** (`Connection unexpectedly closed`) | `.env`-এ `EMAIL_HOST_PASSWORD` ভুল/খালি — Gmail ভুল App Password পেলে সংযোগ কেটে দেয়। যাচাই: `cd ~/fincore/backend && source ~/.virtualenvs/fincore/bin/activate && python manage.py check_email`। ঠিক থাকলে `python manage.py check_email --send you@example.com`। |
| **পাসওয়ার্ড ভুলে গেছেন** | Bash কনসোলে: `cd ~/fincore/backend && source ~/.virtualenvs/fincore/bin/activate && python manage.py changepassword আপনারইউজারনেম` |
| **`unzip: command not found`** | PA-তে সাধারণত থাকে; না থাকলে `python -m zipfile -e ~/fincore-pythonanywhere.zip ~/fincore` ব্যবহার করুন। |
